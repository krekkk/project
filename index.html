Cara Edit

5 LANGKAH · 2 MENIT
  1. Buka index.html pakai Notepad / VS Code / apa aja.
  2. Cari https://drive.google.com/ — itu link contoh. Ganti dengan link Drive kamu.
  3. Nama aset ada di tag h3, nomor slot ada di class="idx".
  4. Nambah aset: copy satu blok article class="card", tempel di baris paling bawah grid, ubah isinya.
  5. Warna & font diatur di style.css (bagian :root) dan link Google Fonts di index.html.

Shortcut: tekan / buat fokus ke kolom pencarian, Esc buat keluar. Situs ini murni teks — nggak ada gambar sama sekali, jadi loadingnya instan.
